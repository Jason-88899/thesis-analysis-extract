# 论文整理流程

先用大纲和关键词限定范围，再读取目标页，不要仅凭摘要补出实验条件。

## 内容、创新点与机理

按任务提取研究问题、设计依据、材料组成、构筑手段、作用机理、性能和局限。机理使用“材料/结构 → 作用过程 → 性能”的因果链，区分作者解释与助手推断。创新性以文中证据为基础，不把作者自述自动等同于已证实的首创。

保留最优样品名称、指标、单位、参照物、测试条件及来源页码。用户要求一段时合并成连贯段落。

## 实验流程

| 项目 | 提取要点 |
|---|---|
| 药品 | 名称、规格、质量、体积、浓度；未给出则注明 |
| 配制 | 加入顺序、溶剂、质量比/摩尔比、混合方法 |
| 反应 | 温度、时间、转速、压力、气氛 |
| 成型 | 设备及影响复现的工艺参数 |
| 后处理 | 洗涤、离心、干燥、活化、交联条件 |
| 测试 | 与性能直接相关的条件和标准 |

按“配料 → 反应/处理 → 成型 → 后处理”写流程。需要时用表格列药品用量，再用一段话说明步骤。补充材料缺失时明确指出，不推测用量。

## 核对

- 回到原文核对小数点、正负号、上下标和单位。
- 区分质量分数、体积分数、相对湿度和材料含水率。
- 区分相对环境、对照样和基材的性能差异。
- 不将提取失败解释为原文未报告，先检查原文或补充材料。
